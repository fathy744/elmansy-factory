# نظام المنسي للغزل والنسيج

نظام إدارة متكامل لمصنع المنسي للغزل والنسيج، بيشتغل من المتصفح ويتثبّت كتطبيق على الكمبيوتر والموبايل (أندرويد وآيفون)، وبيشتغل كمان من غير إنترنت ويزامن أول ما النت يرجع.

**الأقسام:** لوحة المصنع وخط الإنتاج · أوامر التشغيل (غزل ونسيج) · الصباغة لدى الغير وأذون التسليم للمصابغ · الماكينات والصيانة · الجودة · المخازن بالمتر والوزن · المبيعات والعملاء · المشتريات والموردين والمصابغ · الخزينة · التقارير الشهرية · العاملين والحضور والمرتبات · المستخدمين والصلاحيات وسجل النشاط.

---

## خطوات التشغيل لأول مرة (حوالي 15 دقيقة، مرة واحدة بس)

### 1) إنشاء مشروع Firebase (مجاني)

1. ادخل على <https://console.firebase.google.com> بحساب جوجل بتاعك.
2. اضغط **Create a project** ← اكتب اسم زي `elmansy-factory` ← كمّل (تقدر تقفل Google Analytics).
3. من القائمة الشمال: **Build ← Authentication ← Get started** ← اختار **Email/Password** ← فعّل أول اختيار ← **Save**.
4. من القائمة: **Build ← Firestore Database ← Create database** ← اختار مكان قريب (مثلاً `europe-west`) ← **Start in production mode** ← **Create**.
5. في Firestore افتح تبويب **Rules**، امسح اللي فيه، والصق محتوى ملف [`firestore.rules`](firestore.rules) كله ← **Publish**.
6. ارجع للصفحة الرئيسية للمشروع ← اضغط أيقونة الويب **`</>`** ← اكتب اسم ← **Register app**.
   هيظهرلك كود فيه `const firebaseConfig = { ... }` — انسخ اللي بين القوسين `{ }`.

### 2) حط بيانات Firebase في النظام

افتح ملف [`config.js`](config.js) هنا على GitHub ← أيقونة القلم ✏️ ← غيّر السطر الأخير ليبقى كده (بالقيم بتاعتك):

```js
window.FIREBASE_CONFIG = {
  apiKey: "....",
  authDomain: "....firebaseapp.com",
  projectId: "....",
  storageBucket: "....",
  messagingSenderId: "....",
  appId: "...."
};
```

← **Commit changes**. (البيانات دي مش سرية، Firebase مصممها تتحط في الموقع، والحماية الحقيقية في ملف القواعد.)

### 3) تشغيل الرابط (GitHub Pages)

1. في المستودع ده: **Settings ← Pages**.
2. في **Source** اختار **GitHub Actions**.
3. افتح تبويب **Actions** واستنى العلامة الخضرا ✅ (دقيقة أو اتنين).
4. الرابط هيبقى: `https://اسم-حسابك.github.io/elmansy-factory/`

### 4) السماح للرابط في Firebase

في Firebase: **Authentication ← Settings ← Authorized domains ← Add domain** ← اكتب `اسم-حسابك.github.io` ← **Add**.

### 5) أول دخول

افتح الرابط ← هيطلب منك **إنشاء حساب صاحب المصنع** (الاسم والإيميل وكلمة المرور).
أول حساب بيتعمل هو المالك وميتغيرش بعد كده — فاعمله إنت بنفسك.

## إضافة العاملين

من **النظام ← المستخدمين والصلاحيات** ← **إنشاء حساب لموظف**: الاسم، الإيميل، كلمة المرور، والوظيفة.
ادّي الموظف الإيميل وكلمة المرور ويدخل بيهم من أي جهاز.

- الوظايف الجاهزة: مدير عام، محاسب، مسؤول مخازن، مسؤول إنتاج، مسؤول مبيعات، شؤون العاملين، مشرف وردية، مشاهد فقط.
- زرار **الصلاحيات** بيخليك تحدد لكل قسم: لا يرى / مشاهدة / تعديل.
- **إيقاف** الحساب بيمنعه فوراً من كل البيانات.
- زرار **كلمة المرور** بيبعت للموظف رابط يغيّر بيه كلمة المرور على إيميله.
- **سجل النشاط** بيوضح مين عمل إيه وإمتى.

> الصلاحيات متطبقة على السيرفر نفسه (ملف `firestore.rules`)، مش بس في الشاشة: الموظف اللي ملوش صلاحية على الخزينة مثلاً، قاعدة البيانات نفسها بترفض تديله بياناتها.

## التثبيت كتطبيق

- **كمبيوتر (Chrome / Edge):** زرار «تثبيت التطبيق» أعلى الصفحة، أو أيقونة التثبيت في شريط العنوان.
- **أندرويد (Chrome):** القائمة ⋮ ← «تثبيت التطبيق».
- **آيفون (Safari):** زرار المشاركة ⬆ ← «إضافة إلى الشاشة الرئيسية».

## نقل البيانات من النسخة القديمة

من النسخة القديمة: **الإعدادات ← تنزيل نسخة احتياطية** (ملف JSON).
في النظام الجديد: **الإعدادات ← استرجاع نسخة احتياطية** واختار الملف.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | النظام كله (الواجهة والحسابات) |
| `platform.js` | الربط مع Firebase وتسجيل الدخول |
| `config.js` | بيانات مشروع Firebase |
| `firestore.rules` | قواعد الأمان والصلاحيات على السيرفر |
| `manifest.webmanifest`, `sw.js`, `icons/` | التثبيت كتطبيق والعمل من غير إنترنت |
| `.github/workflows/pages.yml` | نشر الرابط تلقائياً مع كل تعديل |
